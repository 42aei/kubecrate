## Variant: Executive glass

### Design stance
A polished overview: calm glass cards, big score, and low-noise summaries for stakeholder inspection.

### Key choices
- Layout: distinct glass layout for validation status.
- Typography: shadcn-like system UI, clear labels, scan-first hierarchy.
- Color: dark shadcn surface with semantic accent.
- Interaction: filters and clickable check rows.

### Trade-offs
- Strong at: manual demos and non-technical inspection sessions.
- Weak at: less dense for power-user triage.

### Best for
- manual demos and non-technical inspection sessions
