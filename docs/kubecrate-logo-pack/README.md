# KubeCrate logo pack

This pack contains repo-ready logo assets for KubeCrate.

## Files

- `svg/kubecrate-logo.svg` - full horizontal logo
- `svg/kubecrate-logo-dark.svg` - full logo on dark background
- `svg/kubecrate-icon.svg` - icon-only mark
- `svg/kubecrate-icon-dark.svg` - icon-only mark on dark background
- `svg/kubecrate-icon-mono.svg` - simple monochrome icon
- `svg/kubecrate-wordmark.svg` - wordmark only
- `png/` - exported PNG variants
- `png/favicon.ico` - basic favicon
- `source/` - original generated concepts used as visual reference

## Suggested GitHub README usage

```html
<p align="center">
  <img src="./assets/kubecrate-logo.svg" alt="KubeCrate" width="640">
</p>
```

## Suggested tagline

> KubeCrate is a minimal CNCF cloud platform in a box.

## Notes

The SVG files are hand-built vector approximations based on the generated concept image. They are suitable as editable starting points for a public repository.
