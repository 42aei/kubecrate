# Backlog

This folder contains lightweight raw captures.

These files are not full specs. They keep near-term work visible until it is ready to become an OpenSpec proposal or implementation slice.

## Format

Each backlog item uses:

- YAML frontmatter
- `## Goal`
- `## Notes`

Nothing more is required in this phase.

## How to use the backlog

- Keep items short and concrete.
- Preserve project language and the two-axis model.
- Expand an item later when it is ready for proposal or execution.
- Prefer backlog entries that can turn into vertical slices.
