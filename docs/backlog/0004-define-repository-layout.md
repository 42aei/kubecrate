## Goal

Define a repository layout that supports small vertical slices and keeps docs, bootstrap installation concerns, and GitOps-managed operation concerns understandable.

## Notes

The layout should reflect the two-axis model without creating too many top-level categories too early.

Favor a structure that stays navigable for contributors who are still learning the platform domain.
